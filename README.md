# دليل الإنشاء + ما أحتاجه منك

هذا مجلد مشروع جاهز (هيكل كامل) مبني على **Python**، يعمل الآن باستراتيجية مثال فقط.
بمجرد وصول ملف الـ PDF أستبدل ملف `src/strategy.py` باستراتيجيتك الحقيقية، ويصبح البوت جاهزاً.

## 1) كيف يعمل البوت (خط التدفق)

```
البورصة (Binance/Bybit/OKX)
        │  شموع OHLCV عبر ccxt
        ▼
   datafeed.py  ──►  strategy.py (استراتيجيتك من الـ PDF)
        │                    │
        │         Signal(symbol, side, entry, SL, TPs)
        ▼                    ▼
   engine.py (مسح كل 60 ثانية + منع التكرار + ترتيب حسب قوة الإشارة)
                             │
                             ▼
                    bot.py ──► تلجرام (قناة/مجموعة/خاص)
```

- **مكثف** = يراقب قائمة كبيرة من الأزواج (أعلى 50–100 زوج سيولة) على فريم صغير، ويرسل حتى N إشارة كل دورة.
- **منع السبام**: `cooldown_minutes` يمنع تكرار نفس الإشارة لنفس الزوج.
- **الإشارة تحتوي**: الزوج، الاتجاه، الدخول، الستوب، 3 أهداف، الرافعة، الفريم، سبب الإشارة، المخاطرة.

## 2) طريقة الإنشاء خطوة بخطوة

**أ. إنشاء البوت على تلجرام**
1. افتح `@BotFather` → `/newbot` → اختر اسماً واسم مستخدم ينتهي بـ `bot`.
2. خذ **التوكن** (شكله `123456:ABC...`).
3. أنشئ قناة/مجموعة، أضف البوت كـ **Admin** (وإلا لن يستطيع النشر).
4. شغّل البوت وأرسل `/id` لتعرف `chat_id` (أو استخدم `@اسم_القناة`).

**ب. التشغيل عندك**
```bash
cd futures-signal-bot
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # ثم ضع التوكن و chat_id
python src/bot.py
```
افتح تلجرام → `/start` → `/status` → `/scan`.

**ج. ضبط الاستراتيجية** — تعديل واحد فقط: `src/strategy.py` (الشروط، الفريمات، الستوب/الأهداف).
**د. الاستضافة** (لتشتغل 24/7): VPS رخيص (Hetzner ~4€/شهر) أو Railway/Fly.io. أوامر: `systemd` أو `docker` أو `pm2`.
**هـ. الاختبار قبل الإطلاق** (مهم جداً): Backtest على بيانات تاريخية + Period تجريبي على قناة خاصة لمدة أسبوعين، ثم قناة حقيقية.

## 4) ما أحتاجه منك ← أرسله هنا

**ضروري (بدونه لا أستطيع البناء):**
1. **ملف الـ PDF** للاستراتيجية — ارفعه في المحادثة مباشرة.
2. **الفريم الزمني** لكل إشارة (5m؟ 15m؟ 1h؟) وهل تحتاج تأكيد من فريم أعلى.
3. **قائمة الأزواج** أو "أعلى X زوج سيولة تلقائياً".
4. **البورصة**: Binance Futures / Bybit / OKX / غيرها (تختلف الأزواج والرافعة).
5. **شكل الستوب والأهداف**: هل يحددها الـ PDF (ATR / نسبة % / قمة سابقة)؟ وكم هدف؟
6. **حد الإشارات**: كم إشارة في اليوم تعتبر "مكثفة" عندك؟ (مثلاً 5–15)

**مهم للجودة:**
7. **البوت إشارات فقط أم ينفّذ الصفقات آلياً؟** (التنفيذ الآلي يحتاج مفاتيح API ويحتاج حماية أكبر + موافقتك).
8. **هل الـ PDF بالعربية؟** إن كان مكتوباً بخط غير واضح أرسل صوراً واضحة للصفحات بدل الملف.
9. **صيغة الرسالة** التي تريدها (أمثلة أو صورة من قناة تعجبك).
10. **إحصائيات الاستراتيجية** إن كانت موجودة (Win rate / R:R / عدد الصفقات) — تساعدني في ضبط الأهداف.

**اختياري:**
11. حساب تيست نيت (Testnet) إن أردت تجربة التنفيذ الآلي بلا مخاطرة.
12. هل تريد أوامر إدارية إضافية (`/pause` `/stats` `/risk`)؟
13. اللغة: العربية فقط أم ثنائية اللغة للرسائل؟

> ملاحظة صريحة: أي بوت إشارات لا يضمن الربح — الـ PDF مهم، لكن الأهم هو الاختبار التاريخي وإدارة رأس المال.
> ولا ترسل أبداً مفاتيح API بصلاحية سحب (Withdraw) — فقط صلاحية تداول.

### ⚠️ ملاحظة مهمة جداً عن Binance
Binance تحجب الـ API على عناوين IP من مناطق/دول معيّنة (خصوصاً سيرفرات أمريكا وسنغافورة). إذا ظهر لك خطأ `451`:
- شغّل البوت من اتصالك المنزلي في الجزائر (عادة يعمل)، أو
- اختر VPS في **أوروبا** (Hetzner ألمانيا / Netcup) — هذه تعمل مع Binance.
- الحل البديل: غيّر `exchange` إلى `bybit` أو `okx` في `config.yaml` (نفس الكود يعمل بلا تعديل، والأزواج تبقى `BTC/USDT:USDT`).

## 7) المرحلة الثانية (بعد وصول الـ PDF)

1. أستبدل `src/strategy.py` باستراتيجيتك (شروط، فريمات، ستوب/أهداف كما في الملف).
2. أضيف `src/backtest.py` لقياس Win rate و R:R وعدد الإشارات يومياً.
3. أضيف `src/executor.py` للتنفيذ الآلي على Binance: هامش معزول، أمر Market، SL/TP عبر `STOP_MARKET` و`TAKE_PROFIT_MARKET`، حجم الصفقة محسوب من `risk_per_trade_pct`.
4. وضع Testnet أولاً (`binanceusdm` + `set_sandbox_mode`) قبل أي مال حقيقي.
